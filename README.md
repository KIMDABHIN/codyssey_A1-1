# AI 프롬프트 관리 프로그램

Python으로 만든 콘솔 기반 AI 프롬프트 관리 프로그램입니다.

자주 사용하는 AI 프롬프트를 한곳에서 관리할 수 있도록 제작했습니다.
프롬프트를 추가하고, 목록을 확인하고, 카테고리별로 조회하거나 키워드로 검색할 수 있습니다.
또한 프롬프트를 수정하거나 삭제할 수 있으며, 자주 사용하는 프롬프트는 즐겨찾기로 관리할 수 있습니다.

## 실행 방법

Python 3.10 이상이 설치된 환경에서 실행할 수 있습니다.

터미널에서 프로젝트 폴더로 이동한 후 다음 명령어를 실행합니다.

    python prompt_manager.py

프로그램이 실행되면 메뉴 번호를 입력하여 원하는 기능을 선택할 수 있습니다.

## 주요 기능

1. 프롬프트 추가
   - 제목, 내용, 카테고리를 입력하여 새로운 프롬프트를 등록합니다.
   - 같은 제목의 프롬프트는 중복해서 등록할 수 없습니다.

2. 프롬프트 목록 보기
   - 등록된 모든 프롬프트를 번호와 함께 확인할 수 있습니다.
   - 제목, 카테고리, 즐겨찾기 여부를 표시합니다.

3. 프롬프트 삭제
   - 원하는 프롬프트를 선택하여 삭제할 수 있습니다.
   - 삭제 전 확인 과정을 거칩니다.

4. 프롬프트 수정
   - 기존 프롬프트의 제목과 내용을 수정할 수 있습니다.
   - 제목 수정 시 중복 여부를 확인합니다.

5. 카테고리별 조회
   - 원하는 카테고리를 선택하여 해당 카테고리의 프롬프트만 확인할 수 있습니다.

6. 프롬프트 검색
   - 키워드를 입력하여 제목, 내용 또는 카테고리에 해당 키워드가 포함된 프롬프트를 검색할 수 있습니다.

7. 프롬프트 상세 보기
   - 선택한 프롬프트의 제목, 카테고리, 즐겨찾기 여부, 전체 내용을 확인할 수 있습니다.

8. 즐겨찾기 추가/해제
   - 원하는 프롬프트를 즐겨찾기에 추가하거나 해제할 수 있습니다.

9. 즐겨찾기 목록 보기
   - 즐겨찾기로 등록한 프롬프트만 모아서 확인할 수 있습니다.

10. 작업 취소
   - 입력 과정에서 q를 입력하면 현재 작업을 취소하고 메인 메뉴로 돌아갑니다.

## 프롬프트 카테고리

프로그램에서는 다음과 같은 카테고리를 사용합니다.

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 데이터 저장 방식

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용하여 관리합니다.

프로그램 실행 중에 추가하거나 수정한 데이터는 프로그램이 실행되는 동안 유지되며,
프로그램을 종료하면 초기화됩니다.

## Git 브랜치 작업

프롬프트 목록 기능을 별도의 Git 브랜치에서 수정하고 커밋한 후,
main 브랜치로 병합하여 Git의 브랜치 및 병합 기능을 활용했습니다.
